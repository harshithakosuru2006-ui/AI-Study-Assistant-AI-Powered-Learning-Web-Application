# AI Study Assistant

An AI-powered web application designed to help students understand
academic concepts through interactive question answering.

## Features

- Ask academic questions
- Generate AI-powered explanations
- Simple and student-friendly responses
- Interactive web interface
- Python Flask backend
- Anthropic API integration
- Input validation
- API error handling
- Responsive design

## Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Python
- Flask

### AI

- Claude
